## Comment ajouter un article

1. Créer un fichier dans `_posts\` nommé `AAAA-MM-JJ-titre-en-anglais.md` ;
2. Commencer par l'en-tête (titre, date, résumé) sur le modèle des articles existants ;
3. Écrire l'article en Markdown, puis sauvegarder sur GitHub (commit + push) ;
4. Le blog se met à jour tout seul en 1 à 2 minutes.
